# Shared mods by Intetsch

A repo with the shared mods I developed.

## Sharedproduct Palm Wood

Adds a new product: Palm Wood

![icon_palm_planks.png](https://raw.githubusercontent.com/Intetsch/shared-mods-Intetsch/27e712c9ade29874f00725c5c55c8d971556a44f/Intetsch_sharedproduct_palm_wood/data/modgraphics/ui/icon_palm_planks.png)

### GUIDs

```markdown
Palm Wood (Product): 1400201040
```

### Usage:

Add the following dependencies to your `modinfo.json`:

```json
"ModDependencies": [
  "https://github.com/Intetsch/shared-mods-intetsch/releases/latest/download/Intetsch_sharedproduct_palm_wood.zip"
]
```
